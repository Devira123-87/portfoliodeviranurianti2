UI/UX Design Project

UI/UX Aplikasi AR Anatomi

Perancangan tampilan antarmuka aplikasi AR Anatomi untuk media pembelajaran interaktif mengenai kerangka manusia dan organ tubuh. Desain dibuat dengan fokus pada pengalaman pengguna modern, navigasi mudah dipahami, serta visual edukatif yang menarik menggunakan Figma.

Ringkasan Proyek

Proyek ini merupakan desain UI/UX aplikasi mobile edukasi berbasis Augmented Reality (AR) yang membantu pengguna mempelajari anatomi tubuh manusia secara interaktif. Desain mencakup onboarding, scan AR, halaman informasi organ, navigasi menu, dan evaluasi pengguna dengan tampilan modern dan user friendly.

Fitur Desain

  • Tampilan mobile modern dan clean
  • Desain interaktif berbasis AR
  • Informasi organ tubuh edukatif
  • Navigasi pengguna intuitif
  • Visual learning experience

Tools yang Digunakan

Figma, UI Design, UX Research, Wireframe, Prototyping, Design System, Mobile Interface Design.
