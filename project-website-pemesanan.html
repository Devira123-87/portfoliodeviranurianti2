Web Programmer

Perpustakaan Digital

Sistem informasi perpustakaan berbasis web yang menyediakan fitur pencarian buku, peminjaman, dashboard admin, dan pengelolaan data buku secara modern dan responsif.

Kembali ke Portofolio Detail Proyek

Ringkasan Proyek

Proyek ini dibuat menggunakan Laravel dan MySQL untuk membantu pengelolaan perpustakaan digital secara efisien. Sistem menyediakan halaman user untuk melihat koleksi buku serta dashboard admin untuk mengelola data buku dan status peminjaman.

Fitur Utama

  • Login dan autentikasi user
  • Dashboard admin
  • CRUD data buku
  • Status peminjaman buku
  • Pencarian buku
  • Tampilan responsive modern

Teknologi

Laravel, PHP, MySQL, Bootstrap, HTML5, CSS3
