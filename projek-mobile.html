Mobile Interactive Project

BrewSpace Cafe Finder App

Aplikasi mobile interaktif bertema cafe finder dengan desain aesthetic coffee style. Aplikasi ini membantu pengguna menemukan cafe terbaik, melihat menu, menyimpan favorit, hingga melakukan pemesanan dengan tampilan modern dan user friendly.

Kembali ke Portofolio Detail Proyek

Ringkasan Proyek

BrewSpace dibuat sebagai aplikasi mobile interaktif dengan konsep clean UI dan coffee aesthetic. Fokus utama pada pengalaman pengguna yang nyaman, navigasi yang mudah, serta tampilan modern untuk eksplorasi cafe yang lebih menarik.

Fitur Utama

  • Search cafe interaktif
  • Rekomendasi cafe populer
  • Favorite cafe
  • Detail menu & rating cafe
  • Keranjang & checkout
  • Profil user modern

Teknologi

Flutter (Mobile Development), Dart (Programming Language)
