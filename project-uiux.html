Web Designer Project

Website Portfolio Modern

Proyek desain dan pengembangan website portfolio modern dengan tampilan minimalis, responsif, dan elegan. Fokus utama pada user interface, kenyamanan pengguna, serta visual yang menarik menggunakan HTML dan CSS.

⬅ Kembali ke Portofolio Lihat Detail

Ringkasan Proyek

Website ini dibuat untuk menampilkan identitas personal dan hasil karya dalam bentuk portfolio online. Desain dibuat modern dan clean dengan kombinasi layout yang responsif sehingga nyaman diakses melalui desktop maupun smartphone.

Fitur Website

  • Landing page modern
  • Tampilan portfolio interaktif
  • Navigation menu responsif
  • Desain clean dan minimalis

Tools yang Digunakan

HTML, CSS, Visual Studio Code (VS Code), dan Figma untuk perancangan desain UI website.
